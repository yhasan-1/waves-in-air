# Waves in Air

A point-and-click narrative puzzle game exploring communication,
cultural differences, and conflict resolution.

## About

The player acts as a courier traveling between communities and
translating information to resolve conflicts and overcome communication
barriers.

The game contains five distinct story areas exploring themes including
isolation, classism, trust, and language barriers.

## Built With

- Godot
- GDScript

## Features

- Point-and-click exploration
- Dialogue and narrative systems
- Communication-based puzzles
- Multiple themed environments
- Custom interaction mechanics
